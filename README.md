# Banco de Dados de Grafos em SQLite

Projeto didático para demonstrar como modelar, popular e consultar estruturas de grafos (Nós e Arestas) utilizando o SQLite e Python.

## Estrutura
- **01_schema.sql**: Criação das tabelas `nos` e `arestas` com chaves estrangeiras.
- **02_dados.sql**: Inserção de dados de exemplo (rede social).
- **03_consultas.sql**: Consultas úteis, incluindo busca de vizinhos e CTEs recursivas.
- **app.py**: Demonstração automatizada em Python.
